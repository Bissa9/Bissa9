- Saved spot stays after the app closes
- Driving route, distance, and compass direction

### [Stampy](https://github.com/Bissa9/Stampy)
A stamp catalog with accounts, a cart, and checkout.

- SwiftUI, Firebase Auth, Firestore, and Storage
- Stripe PaymentSheet, with the charge amount taken from the order on the server
- Firestore rules so a signed-in user can change only their own stamps and orders
